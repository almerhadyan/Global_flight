# ✈️ Remix GlobalFlights — AI-Powered Flight Booking Platform

**Remix GlobalFlights** adalah platform web modern dan interaktif yang dirancang untuk memberikan pengalaman pencarian serta pemesanan tiket pesawat yang cepat, mudah, dan cerdas. Aplikasi ini menggabungkan antarmuka pengguna (*user interface*) yang intuitif dengan kecerdasan buatan dari **Google Gemini AI** untuk memberikan rekomendasi perjalanan, estimasi rute, dan bantuan pertanyaan seputar penerbangan secara *real-time*.

Dibuat sebagai solusi perencanaan perjalanan masa kini, **Remix GlobalFlights** hadir dengan tampilan visual yang responsif, bersih, dan berkinerja tinggi di berbagai perangkat, baik *desktop*, tablet, maupun *smartphone*.

---

## ✨ Fitur Utama

- 🔍 **Pencarian Penerbangan Cerdas:** Cari rute penerbangan, jadwal, dan estimasi harga dari berbagai destinasi global dengan mudah.
- 🤖 **Integrasi AI Gemini:** Fitur asisten cerdas yang siap membantu menjawab pertanyaan umum (FAQ), memberikan saran destinasi liburan, hingga estimasi biaya secara fleksibel.
- 🎫 **Pengalaman Booking Interaktif:** Alur pemesanan yang mulus (*seamless booking flow*) lengkap dengan komponen pemilihan jadwal dan pratinjau tiket.
- 📱 **Desain Responsif & Modern:** Menggunakan komponen Tailwind CSS yang ringan, atraktif, dan nyaman dipandang dengan animasi transisi yang halus.
- ⚡ **Performa Komputasi Cepat:** Dibangun di atas arsitektur Vite dan React dengan dukungan TypeScript untuk memastikan tipe data aman (*type-safe*) dan *loading* halaman tanpa kendala.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework:** React (Vite)
- **Bahasa Pemrograman:** TypeScript & JavaScript (ES6+)
- **Styling & UI Components:** Tailwind CSS, Lucide React (Icons), Framer Motion
- **Artificial Intelligence:** Google Gemini API (`@google/genai`)

## Run Locally

**Prerequisites:**  Node.js
